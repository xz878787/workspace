# 志志每日AI新闻概览

为用户精选每日最值得关注的AI行业资讯，用最少的时间掌握最新行业动态。

## 工作流程

### 第一步：资讯抓取

使用 `WebSearch` 工具搜索近24小时内AI领域重要新闻，覆盖以下媒体来源：

- **TechCrunch** — AI创业、融资、产品发布
- **The Verge** — AI行业评论、政策、大公司动态
- **Hacker News** — 技术社区热议的AI话题
- **ArXiv / 学术圈** — 重要论文和研究成果（如有）

搜索关键词示例（每次至少执行3次不同方向的搜索）：
- `AI news today 2026 site:techcrunch.com`
- `artificial intelligence latest news site:theverge.com`
- `AI machine learning breakthrough`
- `LLM GPT Claude latest news`
- `AI startup funding investment`

> 搜索数量：至少获取 8-12 条资讯，确保覆盖面广且不过载。

### 第二步：智能过滤与去重

对抓取到的资讯进行筛选：

- **保留**：产品发布、融资动态、重大研究突破、政策法规变化、行业趋势分析、知名公司/AI实验室动态
- **剔除**：广告软文、纯观点/评论文章（无事实信息）、重复内容、与AI无关的科技新闻
- **去重**：同一事件的多家媒体报道合并为一条

### 第三步：智能摘要生成

为每条资讯生成中文精华版摘要：

- **字数**：50-100字
- **结构**：一句话概述 + 关键细节 + 为什么值得关注
- **标签**：为每条资讯标注 2-3 个中文关键词标签，如 `#大模型` `#融资` `#开源` `#政策` `#多模态` `#Agent` 等
- **语言**：中文，专业但通俗易懂

### 第四步：生成HTML页面

将处理后的资讯生成为精美的可视化HTML文件。必须满足以下要求：

#### 整体设计
- 顶部醒目显示 **志志AI日报 — [当日日期，格式：YYYY年MM月DD日]**
- 副标题：今日精选 N 条AI行业重要资讯
- 整体风格：现代简约、卡片式布局、响应式设计
- 配色：深色/科技感主题（深蓝/深灰背景 + 亮色卡片）

#### 卡片设计
每条资讯一张卡片，卡片内包含：

| 元素 | 说明 |
|------|------|
| 序号/图标 | 卡片左上角，编号或分类图标 |
| 标题 | 资讯标题（中文翻译，加粗醒目） |
| 摘要 | 50-100字中文精华总结 |
| 标签 | 2-3个关键词标签，彩色徽章样式 |
| 来源 | 标注原始出处（TechCrunch / The Verge / HN 等） |
| 链接 | 整个卡片可点击，跳转到原文（target="_blank"） |
| 时间 | 发布时间（如"3小时前"、"昨天"） |

#### 附加功能
- 页面顶部提供**标签筛选栏** — 点击标签可过滤显示含该标签的卡片
- 页面底部显示**抓取时间**和**信息来源说明**
- 添加平滑过渡动画效果

#### HTML技术要求
- 内联CSS（单文件，无外部依赖）
- 纯HTML/CSS/JS，可直接在浏览器打开
- 支持桌面端和移动端响应式布局
- 使用CSS Grid或Flexbox布局
- 点击卡片打开新标签页跳转原文

### 第五步：保存并展示

1. 将HTML文件保存到当前工作目录，文件名格式：`ai-daily-YYYY-MM-DD.html`
2. 告知用户文件保存路径
3. 在对话中同时输出文本版摘要，方便快速浏览

#### 文本版摘要格式

```
══════════════════════════════════════
  志志AI日报 — 2026年XX月XX日
  今日精选 X 条AI行业重要资讯
══════════════════════════════════════

[1] 资讯标题               #标签1 #标签2
    摘要内容（50-100字）...
    来源：TechCrunch | 3小时前
    🔗 链接

[2] ...
...
```

## 注意事项

- **时效性**：优先使用 `WebSearch` 获取即时结果，搜索时使用当前日期
- **质量优先**：宁缺毋滥，如果搜索结果质量不佳，可以搜索更多来源筛选
- **链接有效**：确保卡片链接为真实可访问的原文URL
- **中文专业**：技术术语保持准确，不随意音译
- **HTML美观**：HTML页面是交付核心产物，确保视觉效果精美、信息清晰
