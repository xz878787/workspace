## 倒排索引
ES 相比于Mysql 最大的核心优势， 基于**倒排索引**
## 倒排索引

普通MySQL 使用的是正向索引：
以一行为单位存储完整数据，检索文本内容时，需要逐行遍历，逐字匹配内容。
数据量越大，文本越长，模糊/文本搜索就越慢，性能越差，不适合大范围关键词检索。
ES 使用倒排索引机制
会自动对text 类型字段进行分词处理，拆解为一个个独立的词条， 再以词条为核心，反向关联所有包含改词条的文档。
倒排索引 关键词-> 文档
